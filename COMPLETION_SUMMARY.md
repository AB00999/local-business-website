## 🚀 Account Creation - Step by Step

### Creating an Account:
```
1. Click "Login" button (top right)
2. Click "Sign up" link
3. Enter:
   - Username: (choose unique name)
   - Password: (min 6 characters)
   - Email: (for password recovery)
4. Click "Create Account"
5. Automatically logged in!
6. Username now shows in top right
```

### Logging In:
```
1. Click "Login" button
2. Enter username and password
3. Click "Login"
4. Session created, username displays
```

### Forgot Password:
```
1. Click "Login" → "Forgot password?"
2. Enter username or email
3. Click "Send Reset Link"
4. Enter new password (min 6 chars) + confirm
5. Click "Reset Password"
6. Login with new password
```

### Logging Out:
```
1. Click your username (top right)
2. Select "Logout"
3. Session cleared, back to login screen
```
